# bidama-todokede

todokede (届出, declarations) stays in blue's core distribution, as a toolchain bidama: blue's own host (`blue-lang-host`, its world judging) uses `todokede/motenashi` from blue's compiled distribution. Use it from blue: `use("todokede/<level>")` needs no `source(...)` row.

This repository keeps the history of the move that did not happen and is archived.
